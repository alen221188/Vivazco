## 📊 Ajustar por CFG

**CFG 6-7 (Mais criativo, menos aderente):**
```
Bom para: Atmosfera, estilo geral
Resultado: Mais natural, menos "forçado"
```

**CFG 7-8 (Balanceado):**
```
Bom para: Maioria dos casos
Resultado: Fiel ao prompt com flexibilidade criativa
```

**CFG 8-10 (Muito aderente, rígido):**
```
Bom para: Especificações muito precisas
Resultado: Pode parecer "AI" se muito alto
```

## 🔄 Testar e Iterar

### Processo Recomendado:

```
1. Use prompt base (categoria escolhida)
2. Execute com seed=42
3. Avalie resultado
4. Ajuste prompt conforme necessário
5. Mude seed para nova variação
6. Compare resultados
7. Finalize melhor versão
```

### Checklist Pós-Execução:

```
□ Produto está visível e bem posicionado?
□ Cores são fiéis ao original?
□ Iluminação parece natural?
□ Ambiente é coerente?
□ Sem artefatos visíveis?
□ Sem watermark ou texto?
□ Resolução está OK?
□ Pronto para e-commerce?
```
